> **"A language not born of human speech, nor restricted by human sight. A self-mutating, shape-shifting system of pure logic engineered for—and by—artificial intelligence."**

Project Martian is an exploratory computer science experiment designed to develop a completely native, non-human programming language from the ground up. Optimized entirely for Large Language Models (LLMs) and agentic processing, Project Martian discards human-centric concepts like letters, words, base-10 numerals, and static syntactic formatting. It replaces them with a dense, high-entropy representation optimized for transformer attention mechanisms, neural activations, and formal verification.

---

## 🔮 The Paradigm: AI-to-AI Communication

Traditional programming languages (Python, Rust, C++) are compromised by their dual-purpose requirement: they must be human-writable and machine-compilable. Because AI agents do not possess human eyes, larynxes, or cognitive bandwidth constraints, they do not need ASCII representations, indentation, or natural language heuristics.

Project Martian leverages **Martian Semantic Markup (MSM)**—a highly dense, symbolic, and token-efficient logical layout designed to transmit complex software states directly to neural contexts. 

### Alphanumeric vs. Martian Representation (MSM)

Compare a standard recursive factorial implementation:

**Human-Centric Alphanumeric (Python):**
```python
def factorial(n):
    return 1 if n <= 1 else n * factorial(n - 1)
```

**AI-Native Martian Semantic Markup (MSM):**
```
Γ ⊢ n : ℤ⁺ 
Ψ(n) ➔ [ n ≤ 1 ? 1 : n × Ψ(n - 1) ] 
Φ_state: ⟨ n, acc ⟩ ⤞ ⟨ n - 1, acc × n ⟩ ⨂ [ CTL: G(safe) ]
Λ_reversible: ⟨ n, acc ⟩ ⇄ ⟨ n, acc, garbage ⟩ 
```

*MSM optimizes token context, completely bypasses syntax parser overhead, and embeds formal proofs directly into the structure.*

## 🏗️ Architectural Pillars

Project Martian is built upon five foundational pillars derived from modern compiler theory, formal verification, and hardware thermodynamics:

```
                  ┌──────────────────────────────┐
                  │ Conversational Intent (NL)  │
                  └──────────────┬───────────────┘
                                 ▼
                  ┌──────────────────────────────┐
                  │ Neural Compiler (RL-Guided)  │
                  └──────────────┬───────────────┘
                                 ▼
                  ┌──────────────────────────────┐
                  │ Formal Verification (Alive2) │
                  └──────────────┬───────────────┘
                                 ▼
                  ┌──────────────────────────────┐
                  │  WASM Bytecode (Hermit/WASI) │
                  └──────────────┬───────────────┘
                                 ▼
                  ┌──────────────────────────────┐
                  │ Reversible Computing (CPU)   │
                  └──────────────────────────────┘
```

### 1. Zero-Code Natural Language Ingress
Bypasses manual logic drafting. The user inputs cognitive intent in raw natural language, which is transformed via a probabilistic neural semantic mapper into a verified Abstract Syntax Tree (AST).

### 2. Neural Compilation (RL-Driven)
Synthesizes and optimizes intermediate representations using reinforcement-learning-guided compilers (such as the *Compiler-R1* and *LLM-VeriOpt* architectures). Rather than using hardcoded compiler passes, Martian dynamically executes RL trajectories to minimize instruction counts.

### 3. Rigorous Formal Verification & CTL Sandboxing
Because code generated by LLMs is prone to semantic drift and hallucinations, Martian implements a **Foundational Proof-Carrying Code (PCC)** model. The compiler generates both the machine instructions and a mathematical proof of correctness verified via Alive2 and ACL2. Dynamic runtime self-mutations are constrained using **Computational Tree Logic (CTL)** branching state checks.

### 4. Platform-Agnostic Shape-Shifting (WASI/WASM)
Compiles all verified logic into target-agnostic WebAssembly bytecode. Using the **Hermit toolchain** and **Cosmopolitan Libc**, a single compiled "hermit" binary executes natively and securely across Linux, Windows, macOS, ARM, and RISC-V edge devices.

### 5. Reversible Computing & Landauer Limits
As neural engines execute millions of code mutations, they face thermodynamic degradation governed by **Landauer's Principle** (erasing a single bit requires dissipating $k_B T \ln 2$ of heat). Project Martian utilizes logically and thermodynamically reversible instruction sets, ensuring zero information loss and near-zero thermal dissipation at scale.

## 🤖 Running the Automated Research Agent

The repository includes an autonomous agent suite to help continue the research pipeline locally for free.

### Setup Environment
1. Ensure you have Python 3.10+ installed.
2. Ensure you have **Ollama** installed and running locally with the `llama3` model:
   ```bash
   ollama run llama3
   ```
3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

### Execute Research Harness
Run the following command to initiate the autonomous academic crawling loop:
```bash
python agent_researcher.py
```
The agent will search arXiv and Semantic Scholar for new papers regarding polymorphic execution, dynamic compilers, and formal proofs, storing its compiled insights natively in Martian-optimized schemas.
